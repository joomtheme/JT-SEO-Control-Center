# JT SEO Control Center 1.0.70

[Download the stable installation ZIP](https://github.com/joomtheme/JT-SEO-Control-Center/releases/download/v1.0.70/pkg_jtseo_v1.0.70.zip)
— [validation report](TEST-REPORT-1.0.70.md), [SHA-256](SHA256SUMS.txt).

Adds **Include menu items** (default off), independently of **Include Joomla
articles**. For menu-only output, enable the new option, disable articles and
regenerate the sitemap. **Include homepage** remains independent.

Install through Joomla **System → Install → Extensions**. Existing installations
can upgrade without uninstalling. JED Checker and real-site checks passed, and
Peter confirmed this feature meets his requirements.

The stable ZIP is byte-for-byte identical to the tested candidate, including its
original test-candidate README. No runtime or installer code changed during promotion.
The Joomla update feed now advertises 1.0.70 stable.
